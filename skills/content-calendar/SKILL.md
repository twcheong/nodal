# Content Calendar

Builds a content/campaign calendar from a brief: given a period, the target channels, and a goal/theme, it lays out a posting schedule with a topic, a draft hook/caption, the channel, and a suggested post date for each slot. Composition only — no new tools: pure LLM planning grounded in SOUL.md brand voice and any collected data, written out with tool-write-xlsx (local) or tool-write-gsheet (shareable). The marketer supplies period, channels, cadence (posts/week), and goal; the skill returns the calendar as a sheet plus a short rationale, so nobody starts a month from a blank page. Trigger phrases: 콘텐츠 캘린더, 콘텐츠 일정, 게시 일정 짜줘, 한 달 콘텐츠 계획, 캠페인 플랜, content calendar, posting schedule, content plan.

## Purpose

Turn a period + channels + goal into a concrete posting schedule (topic, draft hook, channel, date per slot) in the brand voice, published as a sheet the marketer can edit and follow.

**KPI:** calendars_shipped

**Platforms:** Instagram, Tiktok, Youtube, Twitter, Linkedin

## Triggers

Activates when the user requests this skill directly.

## Behavior

### 1. Collect Data — Resolve the brief and brand context

- - Resolve the brief from the user's request (infer defaults, ask only for what's genuinely missing):
- period: date range to plan, e.g. 이번 달 / next 4 weeks. Default: next 4 weeks.
- channels: which platforms. Default: the channels the user usually posts to (from data), else instagram.
- cadence: posts per week per channel. Default: 3.
- goal: the theme/objective for the period (launch, engagement, sales, awareness).
- format: "sheet" (Google) or "xlsx" (local). Default: xlsx.
- - Read SOUL.md for brand voice and banned phrasing so draft hooks match the brand.

### 2. Strategize — Draft the calendar slots

Balance angles across the period (mix education, social proof, promotion, behind-the-scenes). Honor SOUL.md voice and banned phrasings. Return { rows: [[header...],[date,channel,topic,hook,format]...] } with a header row first, and a 2-3 bullet rationale for the overall arc.
