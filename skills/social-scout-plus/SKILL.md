# Social Scout Plus

Extends Data Scout to the channels it doesn't emphasize — TikTok, X (Twitter), and LinkedIn — collecting recent posts and their engagement signals via the built-in browser tool (no new tool). Note x_search is denied at runtime, so X is read through the browser, not the search tool. The marketer supplies a profile/handle/hashtag and depth per channel; the skill drives the browser to read public posts, stores a structured snapshot in data/raw alongside data-scout's output, and hands off for analysis. Login-gated views prompt the user to authenticate — credentials are never stored. Trigger phrases: 틱톡 수집, X 수집, 트위터 수집, 링크드인 수집, 소셜 수집 확장, social scout, tiktok scrape, linkedin posts, twitter collect.

## Purpose

Collect recent posts and engagement metrics for the user's target profile/handle/hashtag on TikTok, X, or LinkedIn, then save a structured snapshot for downstream analysis.

**KPI:** items_collected

**Platforms:** Tiktok, Twitter, Linkedin

## Triggers

Activates when the user requests this skill directly.

## Behavior

### 1. Collect Data — Read posts across the requested channels

- - Resolve scope from the user's request:
- channel: tiktok / twitter / linkedin (one or more).
- target: profile handle, hashtag, or search query.
- depth: latest N posts / date range. Default: latest 30.
- data type: posts, engagement (likes/comments/shares/views), bio. Default: posts + engagement.
- Open **Tiktok** browser session (as `tk`)
- Extract **Post** records from `tk` (limit 30, order by published_at desc) → store as `$tiktok_posts`
- Extract **Metric** records from `tk` (where post_id = $tiktok_posts.id) → store as `$tiktok_posts`
- - If channel includes twitter: open the X profile/search for {target} in the browser and read the latest posts + engagement. Do NOT use x_search (denied at runtime).
- - If channel includes linkedin: open the LinkedIn profile/company page for {target} and read recent posts + reactions/comments.
- - Handle infinite scroll until depth is reached. If login is required, prompt the user to authenticate — never store credentials.
- - Merge all channels into one normalized list of { channel, url, text, published_at, metrics }.
- Save `$social_posts` as `social_{channel}_{date}` → `~/.openclaw/workspace/twixy/data/raw/`

### 2. Track Results — Report and hand off

- Load `social_{channel}_{date}` from `~/.openclaw/workspace/twixy/data/raw/` → `$posts`
- - Report: "[Social Scout+] Collected {count} items from {channel} for {target}" and the relative save path (e.g. data/raw/social_{channel}_{date}.json).
- Emit signal `social_scout_complete`
- WITH payload = { channel: $channel, count: $posts.count }
- TO SKILL "Watchtower"
