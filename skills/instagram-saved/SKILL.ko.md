# Instagram Saved Reels (인스타그램 저장 릴스)

사용자의 인스타그램 저장 포스트로 이동해 최근 저장된 릴스 5개를 추출하고, 각각의 likes/comments 를 수집합니다.

## 목적

사용자가 가장 최근에 저장한 인스타그램 릴스/포스트 5개를 (화면상 시각 위치 순서로 정렬해) 추출한 뒤, 각 포스트를 방문해 인게이지먼트 데이터(좋아요·댓글)를 수집합니다.

**KPI:** posts_collected

**플랫폼:** Instagram

## 트리거 (Triggers)

사용자가 저장된 릴스, 저장된 포스트, 또는 저장 컬렉션의 인스타그램 인게이지먼트 데이터를 요청할 때 활성화.

## 동작 (Behavior)

### 페이즈 1 — 저장 포스트로 이동

**유일한 정답 경로:**
1. `https://www.instagram.com/` 열기
2. Snapshot 으로 인스타그램 UI 로드 확인 (`snapshotFormat=aria, refs=role` — selector 금지, labels 금지)
3. 햄버거 메뉴(☰, 좌측 사이드바 우상단) 클릭
4. "Saved" 클릭
5. "All Posts" 클릭

**지름길 (대화에서 유저네임을 이미 아는 경우):**
- 바로 `https://www.instagram.com/{username}/saved/all-posts/`

**금지:**
- ❌ `https://www.instagram.com/saved/` (깨진 URL)
- ❌ 프로필 페이지 먼저 가기
- ❌ 유저네임 검색
- ❌ "Switch", "Log in", 계정 관련 버튼 클릭

페이즈 1 에서는 snapshot 과 클릭이 올바른 동작 — 햄버거 메뉴, "Saved", "All Posts" 를 찾아 클릭해야 하므로. 여기서는 evaluate/DOM 사용 금지.

### 페이즈 2 — 그리드에서 포스트 URL 추출

🚨 **그리드 썸네일은 이미지-only — ARIA 가 아무것도 보지 못함. 필수 snapshot 1회 후, 페이즈 2 의 모든 추가 액션은 evaluate 만 사용. 어떤 상황에서도 snapshot 추가 금지.**

all-posts URL 도달 후:
1. **5초 대기** (`browser act kind=wait timeMs=5000`) — 그리드 렌더에 시간 필요.
2. **정확히 1회 snapshot** — evaluate 가 돌기 위한 페이지 컨텍스트 수립용. 내용 읽기용 아님.
3. evaluate 를 **메서드 A 먼저**, 실패 시 메서드 C 로 실행.

**메서드 A (기본) — 시각 위치 정렬:**
```javascript
() => {
  const seen = new Set();
  const results = [];
  const links = [...document.querySelectorAll('a[href*="/p/"], a[href*="/reel/"]')]
    .map(a => ({ a, rect: a.getBoundingClientRect() }))
    .filter(({ rect }) => rect.width > 0 && rect.height > 0)
    .sort((x, y) => x.rect.top !== y.rect.top ? x.rect.top - y.rect.top : x.rect.left - y.rect.left);
  for (const { a } of links) {
    const m = a.href.match(/instagram\.com\/(p|reel)\/([A-Za-z0-9_-]+)\/?/);
    if (m && !seen.has(m[2])) {
      seen.add(m[2]);
      results.push(a.href.split('?')[0]);
      if (results.length >= 5) break;
    }
  }
  return results;
}
```

**메서드 C (폴백, A 실패 시에만) — DOM 순서:**
```javascript
() => {
  const seen = new Set();
  const results = [];
  for (const a of document.querySelectorAll('a[href*="/p/"], a[href*="/reel/"]')) {
    const m = a.href.match(/instagram\.com\/(p|reel)\/([A-Za-z0-9_-]+)\/?/);
    if (m && !seen.has(m[2])) {
      seen.add(m[2]);
      results.push(a.href.split('?')[0]);
      if (results.length >= 5) break;
    }
  }
  return results;
}
```

**두 evaluate 메서드 모두 실패 시 폴백:**
- Snapshot 텍스트에서 URL 추출. Snapshot 에 `/url: /p/XXXXX/` 엔트리가 보임 — 등장 순서대로 최초 5개 고유 `/p/` 또는 `/reel/` URL 수집. 포스트 ID 로 중복 제거.

**규칙:**
- evaluate 가 빈 배열 반환 → 스크롤 후 최대 3회 재시도. 확인 불필요.
- ARIA 썸네일 클릭으로 전환 금지.
- 🚨 **항상 전체 URL 보고 — 절대 잘라내지 말 것, `…` 사용 금지, 축약 금지.** 각 URL 은 완전해야 함: `https://www.instagram.com/p/FULL_POST_ID/`
- 각 URL 은 `browser open` 으로 직접 열기. **ARIA ref 로 썸네일 클릭 절대 금지** — 썸네일은 이미지-only 라 ARIA 텍스트 라벨이 없음. 썸네일 ref 클릭은 포스트 1개만 열뿐 5개 URL 추출 불가.

### 페이즈 3 — 인게이지먼트 데이터 추출 (포스트별)

5개 포스트 URL 각각에 대해 `browser open` 후 실행:
```javascript
() => ({
  url: location.href,
  likes: document.querySelector('button[aria-label*="like"] span, section span')?.innerText || null,
  comments: document.querySelector('span[aria-label*="comment"]')?.innerText || null
})
```

**루프 규칙:**
- 포스트 1 열기 → evaluate → 포스트 2 열기 → evaluate → … 5번까지.
- **첫 포스트에서 멈추지 말 것.**
- **중간에 "원하면 이어서 할게요" 묻지 말 것.** 확인 없이 5개 모두 완료.
- likes/comments 가 `null` → **"N/A"** 로 기록하고 다음으로. 단일 실패로 루프 중단 금지.

**각 포스트 후:**
- **X 버튼** (모달 닫기) 클릭으로 saved 그리드로 복귀.
- `https://www.instagram.com/` 로 이동하거나 뒤로가기 사용 금지.
- 실수로 홈으로 리다이렉트된 경우 → saved all-posts URL 로 직접 복귀. 전체 플로우 재시작 금지.

### 출력

결과를 표로 보고: 각 5개 포스트의 URL, likes, comments. 확인 안 된 필드는 "N/A" 로 표기. 원본 출력을 `$RAW/instagram_saved_engagement_{date}` 에 저장.
