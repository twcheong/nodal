# Google Docs Report

When a stakeholder lives in Google Workspace, a local PDF is friction. This skill takes the most recent analytics insight (or a user-provided source), normalizes it into Docs blocks, and creates the document via tool-write-gdoc. Returns the share URL so the orchestrator can drop it into chat.

## Purpose

Convert an analytics insight into a properly headed Google Docs document and surface the URL.

**KPI:** gdoc_reports_shipped

**Platforms:** Instagram, Tiktok, Linkedin, Twitter, Youtube

## Triggers

Activates when the user requests this skill directly.

## Behavior

### 1. Analyze — Resolve the source insight

- Load `latest` from `~/.openclaw/workspace/twixy/data/insights/` → `$insight`
- Spawn **structurer**:
  - Task: "Convert the insight markdown into Docs blocks for tool-write-gdoc — array of { type:'title'|'h1'|'h2'|'h3'|'p'|'bullet', text }. Map the headline to a single 'title' block. Flatten nested bullets to one level (Docs renders cleaner). Strip raw URLs out of headings."
  - Input: `$insight`
  - Output: `$payload`

### 2. Track Results — Make sure Google is connected

- - Call tool-google-status. If !connected, abort with a friendly message that points the user to Settings → Google Workspace → Connect.

### 3. Track Results — Create the Google Doc and announce the URL

- Set `$title` = "{insight.title} — {date}"
- - Call tool-write-gdoc with payload = { title: $title, blocks: $payload.blocks }
- - The handler returns { ok, documentId, url, title }. Use $url verbatim — do not rewrite.
- Emit signal `gdoc_report_ready`
- WITH payload = { documentId: $documentId, url: $url, title: $title }
- TO SKILL "Watchtower"
