# Sentiment Scan

Reads comment/review/DM text already collected in the workspace (data/raw, data/insights) and produces a sentiment read: positive/negative/neutral ratio, the top recurring complaints and praises, and representative quotes for each. Pure LLM reasoning — no new tools, no external API: the read tool (or tool-read-xlsx for tabular exports) sources the text, an LLM sub-agent scores tone and clusters themes. The marketer supplies which file/dataset to scan and optionally a channel filter; the skill returns the sentiment breakdown plus an actionable summary of what to fix first. Trigger phrases: 감성 분석, 반응 분석, 평판 분석, 댓글 긍부정, 불만 요약, sentiment analysis, sentiment scan, 리뷰 분석, VOC 요약.

## Purpose

Score collected customer text for sentiment, cluster the recurring complaints and praises with representative quotes, and tell the marketer the single most important thing to address.

**KPI:** sentiment_scans_shipped
**Window:** 30 days

## Triggers

Activates when the user requests this skill directly.

## Behavior

### 1. Collect Data — Load the text to analyze

- - Resolve scope from the user's request:
- source: which file/dataset holds the text (reviews, comments, DMs). Default: latest under data/insights/, then data/raw/.
- channel: optional platform filter (instagram / naver / appstore, etc.). Default: all.
- Load `latest` from `~/.openclaw/workspace/twixy/data/insights/` → `$text_data`
- - If the source is an .xlsx export, call tool-read-xlsx with relPath = the file under data/raw/ or data/insights/.
- - If the source is markdown/JSON, read the relevant files under `~/.openclaw/workspace/twixy/data/raw/` / `~/.openclaw/workspace/twixy/data/insights/` directly.
- - If no text is found, tell the user to collect comments/reviews first (Data Scout) and stop — do NOT invent feedback.

### 2. Analyze — Score tone and cluster themes

- Spawn **sentiment_scorer**:
  - Task: "Analyze this collection of customer text (comments/reviews/DMs). Classify each item's tone as positive / negative / neutral and compute the overall ratio. Cluster the negative items into the top recurring complaints and the positive items into the top recurring praises; for each cluster give a label, an approximate count, and 1-2 representative verbatim quotes. Then name the single highest-priority issue to fix and why. Return { ratio: { positive, negative, neutral }, complaints:[{label,count,quotes}], praises:[{label,count,quotes}], fix_first: 'one line', headline: 'one line' }. Base everything on the provided text — do not add feedback that is not there."
  - Input: `$text_data`
  - Output: `$sentiment`
- Save `$sentiment` as `sentiment_{date}` → `~/.openclaw/workspace/twixy/data/insights/`

### 3. Track Results — Present the sentiment read

- - Present in chat: headline first, then the positive/negative/neutral ratio, the top complaints and praises (label + count + a quote each), and the fix-first recommendation.
- - If the user asked to save: call the write tool to persist a markdown report at "`~/.openclaw/workspace/twixy/data/insights/`/sentiment_{date}.md" and report the relative path.
- Emit signal `sentiment_ready`
- WITH payload = { ratio: $sentiment.ratio, fix_first: $sentiment.fix_first }
- TO SKILL "Watchtower"
