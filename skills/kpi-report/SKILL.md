# KPI Report

Aggregates the marketing data already sitting in the workspace (data/raw, data/insights) into a period-over-period KPI summary and ships it as a PDF or a Google Sheet. Composition only — no new tools: tool-read-xlsx / read for the raw data, an LLM sub-agent for aggregation + narrative, and tool-write-pdf or tool-write-gsheet for the deliverable. The marketer supplies the period, which channels/metrics to roll up, and the output format; the skill returns the report path (or Sheet URL) plus a short headline of the key movements. Pair it with a cron schedule (e.g. schedule: \"0 9 * * 1\") to get a standing weekly/monthly KPI report with no manual trigger. Trigger phrases: KPI 리포트, 성과 집계, 주간 리포트, 월간 리포트, 지표 정리해줘, kpi report, performance summary, weekly report, metrics roundup.

## Purpose

Read the marketing data already in the workspace, aggregate the requested KPIs for the requested period (with period-over-period deltas), and publish a clean PDF or Google Sheet the marketer can share.

**KPI:** kpi_reports_shipped
**Window:** 7 days

**Platforms:** Instagram, Tiktok, Linkedin, Twitter, Youtube

## Triggers

Activates when the user requests this skill directly.

## Behavior

### 1. Collect Data — Resolve scope and load the source data

- - Resolve report scope from the user's request (infer sensible defaults — do not over-ask):
- period: reporting window, e.g. last 7 days / last 30 days / a month name. Default: last 7 days.
- channels: which platforms to include. Default: every channel present in the data.
- metrics: which KPIs to roll up — reach, impressions, engagement_rate, followers, views, etc. Default: the core set available in the source.
- format: "pdf" (share-ready) or "sheet" (further pivoting). Default: pdf.
- data location: where the source lives. Default: data/insights/ first, then data/raw/.
- Load `latest` from `~/.openclaw/workspace/twixy/data/insights/` → `$insight_data`
- - If the source is an .xlsx, call tool-read-xlsx with relPath = the file under data/raw/ or data/insights/. It returns { sheets: [{ name, rows }] } (first 200 rows/sheet).
- - If the source is markdown/JSON, read the relevant files under `~/.openclaw/workspace/twixy/data/raw/` / `~/.openclaw/workspace/twixy/data/insights/` directly.
- - If no data is found for the period, abort with a friendly message telling the user to collect it first (Data Scout) — do NOT fabricate numbers.

### 2. Analyze — Compute KPIs and write the narrative

- Spawn **kpi_aggregator**:
  - Task: "Aggregate the source data into the requested KPIs for the requested period. For each metric: total (or average for rate metrics), the value for the prior comparable period, and the delta (absolute + %). Break the numbers down by channel when channel data is present. Then write a short narrative: 3-5 bullets on what moved and the single most important finding. Return a normalized payload with (1) kpi_rows for tabular output — array of { metric, channel, value, prior, delta_pct } with a header row first, and (2) report_blocks for PDF — array of { type:'h1'|'h2'|'p'|'bullet'|'table', ... } with the headline, the narrative bullets, and the KPI table. Do not invent metrics absent from the source; mark missing values N/A."
  - Input: `$insight_data`
  - Output: `$kpi`
- Save `$kpi` as `kpi_aggregate_{date}` → `~/.openclaw/workspace/twixy/data/insights/`

### 3. Track Results — Write the report and announce the path

- Set `$stem` = "kpi_report_{period}_{date}"
- - If format == "pdf": call tool-write-pdf with relPath = "`~/.openclaw/workspace/twixy/data/reports/`/{stem}.pdf" and payload = { title: "KPI Report — {period}", blocks: $kpi.report_blocks }. The handler returns { ok, relPath, bytes }.
- - If format == "sheet": first call tool-google-status; if !connected, abort with a friendly message pointing to Settings → Google Workspace → Connect. If connected, call tool-write-gsheet with payload = { title: "KPI Report — {period}", sheets: [{ name: "KPIs", rows: $kpi.kpi_rows }] }. The handler returns { ok, spreadsheetId, url, sheets } — use $url verbatim.
- - Report to the user: the relative report path (e.g. data/reports/kpi_report_last-7-days_2026-06-26.pdf) or the Google Sheet URL, plus the one-line headline finding from the aggregation.
- - When this skill runs on a cron schedule, the same report regenerates automatically each period — surface the new path/URL in the scheduled-run notification.
- Emit signal `kpi_report_ready`
- WITH payload = { stem: $stem, format: $format, period: $period }
