# Watchtower

Monitor marketing platforms continuously and alert on KPI changes.

## Purpose

Track key metrics across the user's platforms, detect spikes or drops against a defined threshold, and trigger the Data Scout when fresh data is needed.

**KPI:** alert_accuracy

**Platforms:** Instagram, Tiktok, Linkedin, Twitter, Youtube

## Triggers

Runs on schedule: `0 9 * * *`

## Behavior

### 1. Collect Data — Check current platform metrics

- - Load watch configuration from `~/.openclaw/workspace/twixy/data/watches/`
- Open **Instagram** browser session (as `ig`)
- Extract **Metric** records from `ig` → store as `$current_metrics`
- Load `platform_metrics_baseline` from `~/.openclaw/workspace/twixy/data/insights/` → `$baseline`

### 2. Analyze — Compare metrics against baseline

- Generate a **Hypothesis** from `$current_metrics`:
  - Question: "whether any tracked metric has crossed the user-defined alert threshold compared to baseline"
  - Store as `$alert_check`
If `$alert_check.confidence > 0.7`:
  - Spawn **alert_writer**:
    - Task: "format an alert message showing: metric name, current value, previous average, change percentage, and suggested action"
    - Input: `$current_metrics`
    - Output: `$alert_message`
- Save `$current_metrics` as `platform_metrics_baseline` → `~/.openclaw/workspace/twixy/data/insights/`

### 3. Track Results — Alert user if threshold crossed, trigger scout if needed

If `$alert_message`:
  - - Send alert to user:
  - - Metric: {name}
  - - Current: {value} | Previous avg: {previous} | Change: {delta}%
  - - Suggested action: [analyze] [scout more data] [ignore]
  - Emit signal `metric_spike_detected`
  - WITH payload = $current_metrics
  - TO SKILL "Data Scout"
- Save `$current_metrics` as `watchtower_log_{date}` → `~/.openclaw/workspace/twixy/data/reports/`
