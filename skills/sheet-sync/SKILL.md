# Sheet Sync

Marketers often keep dashboards in Google Sheets but generate raw data with the local Excel pipeline. This skill mirrors one to the other in a single shot. Direction is decided by what the user names — if they point at a local .xlsx, push it up; if they point at a spreadsheetId, pull it down. Tabs/sheet names round-trip 1:1.

## Purpose

Move tabular data between the two stores without the marketer copy-pasting cells.

**KPI:** sheet_sync_runs

**Platforms:** Instagram, Tiktok, Linkedin, Twitter, Youtube

## Triggers

Activates when the user requests this skill directly.

## Behavior

### 1. Track Results — Make sure Google is connected

- - Call tool-google-status. If !connected, abort with a friendly message pointing to Settings → Google Workspace.

### 2. Analyze — Decide push or pull

- Set `$direction` = "push" IF user named a local .xlsx, ELSE "pull"

### 3. Track Results — Read local, write Sheet

- SKIP UNLESS $direction == "push"
- - Call tool-read-xlsx with relPath = $localXlsx. Returns { sheets: [{ name, rows }] }.
- - Call tool-write-gsheet with payload = { title: $localXlsx basename, spreadsheetId: $existingId (optional), sheets: $sheets }.
- - Handler returns { ok, spreadsheetId, url, sheets }.
- Emit signal `sheet_pushed`
- WITH payload = { source: $localXlsx, spreadsheetId, url }
- TO SKILL "Watchtower"

### 4. Track Results — Read Sheet, write local

- SKIP UNLESS $direction == "pull"
- - Call tool-read-gsheet with spreadsheetId = $sheetId, options = { range: $tab + "!A1:ZZ500" } per tab.
- - Aggregate rows into payload = { sheets: [{ name: $tab, rows }] } across tabs.
- - Call tool-write-xlsx with relPath = "`~/.openclaw/workspace/twixy/data/reports/`/sheet_{spreadsheetId}_{date}.xlsx" payload.
- Emit signal `sheet_pulled`
- WITH payload = { spreadsheetId: $sheetId, relPath: $localXlsx }
- TO SKILL "Watchtower"
