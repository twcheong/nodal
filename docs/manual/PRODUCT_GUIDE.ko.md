# Twixy 제품 소개

**마케팅 실무의 반복 작업을 대신 실행하는 데스크탑 어시스턴트**

---

## 1. 한 줄로 말하면

> 조사하고, 정리하고, 문서로 만드는 일 — 매번 손으로 하던 그 과정을 한 번만 설명해두면, 다음부터는 Twixy가 대신 실행합니다.

**누구를 위한 제품인가**

2~10명 규모의 마케팅·소셜미디어 에이전시. 특히 이런 상황이라면 잘 맞습니다.

- 클라이언트가 늘 때마다 **똑같은 조사 과정을 처음부터 반복**하고 있다
- 잘하는 직원의 업무 방식이 **그 사람 머릿속에만** 있다
- 대표가 지금 무슨 작업이 돌아가는지 알려면 **물어봐야** 한다
- AI를 쓰고는 있는데, 매번 **프롬프트를 다시 붙여넣고** 있다

---

## 2. 어떤 일을 대신하나

### 시나리오 1 — 신규 클라이언트 경쟁사 조사

**지금**: 담당자가 경쟁사 인스타 계정을 하나씩 열어 팔로워 수와 최근 게시물을 확인하고, 웹사이트에서 진행 중인 프로모션을 찾아보고, 스프레드시트에 옮겨적습니다. **2~3시간.**

**Twixy로**: 클라이언트명과 경쟁사 목록을 넣고 실행합니다. 브라우저가 실제로 각 계정과 사이트를 돌면서 자료를 모으고, 비교표와 관찰 요약이 담긴 문서 하나로 정리해 저장합니다. 담당자는 **조립하는 대신 검토합니다.**

**그리고 여기서부터가 핵심입니다.** 다음 클라이언트는 이름만 바꿔서 다시 실행하면 됩니다. 90%가 끝난 상태에서 시작합니다.

![실행 중 화면 — 브라우저가 실제로 경쟁사 페이지를 돌고, 진행 상황이 실시간으로 보입니다 (화면 예시)](images/03-run-browser.png)

### 시나리오 2 — 정기 리포팅

**지금**: 매주 같은 데이터를 같은 곳에서 긁어와 같은 형식으로 옮깁니다. 담당자가 휴가면 밀립니다.

**Twixy로**: 그 과정을 워크플로로 한 번 만들어두고 매주 실행합니다. 팀원 누구나 같은 절차를 실행할 수 있고, 결과 형식이 흔들리지 않습니다.

![저장된 워크플로 — 단계가 그림으로 보이고, 사람이 확인하는 단계를 끼울 수 있습니다 (화면 예시)](images/06-workflow-canvas.png)

### 시나리오 3 — 제안서·보고서 만들기

**지금**: 조사 결과를 슬라이드로 옮기고, 색을 맞추고, 넘친 글자를 줄입니다.

**Twixy로**: 내용을 설명하면 슬라이드가 그려집니다. 색과 레이아웃은 **눌러서 고르고**(고르기 전에 실제 모습이 보입니다), 클라이언트 브랜드 색을 하나 넣으면 덱 전체가 그 색에 맞춰집니다. 마음에 안 드는 장만 골라서 고칩니다. `.pptx` 파일로 내보내면 끝입니다.

![덱 만들기 화면 — 왼쪽에서 색을 고르면 즉시 바뀝니다 (화면 예시)](images/05-deck-designer.png)

### 실제로 완료된 작업들

실제로 완료된 작업들을 유형별로 정리했습니다.

| 유형 | 실제 사례 |
|---|---|
| 수집 → 표 | 인스타그램 게시물 30개 수집 · 영상당 유튜브 댓글 100개 표로 정리 · Threads/X 게시물 데이터 엑셀 정리 |
| 수집 → 분석 → 문서 | 모은 댓글 분석 후 슬라이드 제작 · 시장 경쟁사 조사 PPT 보고서 · 엑셀 데이터 분석 PPT |
| 조사 → 배포용 문서 | 업무 가이드 PDF 제작 · 영상 리서치 PDF 정리 · 웹사이트 SEO 점검 리포트 |
| 파일 정리·변환 | 파일 형식 변환 · 열 순서 교정 · 특정 열만 뽑아 키워드 분석 · 표 안의 외국어 번역 |
| 대량 링크 조사 | 업체 웹사이트 45곳을 각각 방문해 연락처 유무 확인 후 정리 |
| 계정 분석 | 프로필 지표 수집 · 게시물 반응 순 정렬 · 댓글 작성자 목록 추출 |

**가장 자주 쓰이는 조합은 "모으고 → 분석하고 → 문서로"** 한 번에 가는 형태입니다. 사람이 하면 반나절 걸리는 일이 한 번의 실행으로 끝납니다.

## 3. 어떻게 작동하나

**① 설명한다**
"경쟁사 세 곳의 인스타를 확인해서 비교표를 만들어줘" 처럼 평소 말로 시킵니다. 코딩도, 설정 화면도 없습니다.

**② 워크플로가 된다**
Twixy가 그 요청을 단계로 나눠 저장합니다. 각 단계는 화면에 도형으로 보이고, 필요하면 **사람이 확인하고 넘어가는 단계**를 끼워 넣을 수 있습니다.

**③ 팀이 재사용한다**
만든 워크플로를 팀에 공유합니다. 신입도 첫날부터 같은 절차를 실행합니다. 누가 언제 무엇을 돌렸고 결과가 무엇인지는 대시보드에 남습니다.

## 4. 다른 방법과 뭐가 다른가

| | **Twixy** | ChatGPT / Claude (채팅) | Zapier / Make | 문서로 만든 매뉴얼 | 사람 더 뽑기 |
|---|---|---|---|---|---|
| 실제 브라우저 작업을 실행 | **○** | △ 제한적 | △ 기술 설정 필요 | ✕ | ○ |
| 클라이언트마다 재사용 | **○** 한 번 저장, 매번 실행 | △ 매번 다시 입력 | △ 건마다 재구성 | ✕ 문서일 뿐 | △ 사람에 따라 |
| 팀이 같은 절차를 공유 | **○** 공유 워크스페이스 | △ 개인 계정 | △ 설정 중심 | △ 읽는 것과 하는 것은 다름 | ✕ 퇴사하면 사라짐 |
| 대표가 진행 상황을 확인 | **○** 대시보드 + 실행 로그 | ✕ | △ 자동화 로그 | ✕ 물어봐야 함 | ✕ 물어봐야 함 |
| 비개발자가 쓸 수 있음 | **○** | ○ | ✕ | ○ | — |

**정리하자면** — 진짜 경쟁자는 다른 제품이 아니라 **대표의 기억력, 열어둔 탭 더미, 그리고 복사-붙여넣기**입니다. Twixy는 쓰던 도구를 대체하지 않습니다. 도구와 도구 사이에서 사람이 직접 옮기고 맞추던 과정을 대신합니다.

> 위 표의 "ChatGPT / Claude"는 **채팅으로 쓰는 경우**를 말합니다. 파일과 브라우저를 직접 다루는 **Claude Cowork**와의 비교는 바로 다음 [**5. Claude Cowork와는 뭐가 다른가**](#ch-5)에서 따로 다룹니다.

**솔직하게 덧붙이면**

- 프로젝트 관리 툴, 콘텐츠 스케줄링 툴을 대체하지 않습니다. 함께 씁니다.
- **모든 사이트에서 항상 성공하지는 않습니다.** 사이트가 구조를 바꾸면 워크플로도 손봐야 합니다. 대신 어디서 왜 멈췄는지가 로그에 남습니다.
- 사람을 대체하는 도구가 아닙니다. 조사를 **조립하는** 시간을 줄여서 **판단하는** 데 쓰게 합니다.

## 5. Claude Cowork와는 뭐가 다른가

가장 자주 받는 질문입니다. **Claude Cowork는 Twixy와 가장 많이 겹치는 제품**이라 따로 정리합니다. 둘 다 데스크탑에서 내 파일을 다루고, 브라우저로 실제 웹 작업을 하고, 문서와 슬라이드를 만듭니다. *(2026년 8월, Anthropic 공식 문서 기준)*

### 한 줄로 말하면

> **Cowork는 세션이고, Twixy는 자산입니다.**

Cowork에서 일을 잘 시키면 **그 세션 안에서** 결과가 나옵니다. Twixy에서 일을 잘 시키면 **팀이 계속 쓰는 워크플로**가 남습니다. 다음 달, 다음 클라이언트, 새로 온 직원이 같은 절차를 그대로 실행합니다.

### 핵심 비교

| | **Twixy** | **Claude Cowork** |
|---|---|---|
| **작업의 단위** | 저장되는 **워크플로** | **세션**(1회 작업) |
| **팀 공유** | 워크플로를 팀 갤러리에 공유, 동료가 복제해 사용 | 세션은 다른 사람과 공유되지 않음 |
| **대표의 가시성** | 팀 전체의 실행 기록·비용·실패 지점을 한 대시보드에서 | 개인 단위로 사용 |
| **중간 확인** | 워크플로 안에 **사람이 승인하는 단계**를 넣어둠 | 진행 중 지켜보다 방향을 바꿔줌 |
| **분야** | 마케팅 전용 — 인스타그램·유튜브·스레드·SEO 수집 도구 내장 | 범용 + 역할별 플러그인(법무·재무·브랜드 보이스 등) |
| **처음 시작** | 킥오프에서 **워크플로 30개와 대시보드를 만들어 드림** | 직접 만들어 사용 |
| **실행 위치** | 내 컴퓨터 | 클라우드 |
| **예약 실행** | 준비 중 | **가능** |

### Twixy를 고르는 이유

- **잘하는 사람의 방식을 팀이 물려받아야 할 때.** Cowork 세션은 그 사람의 것으로 남습니다. Twixy 워크플로는 팀 자산이 되어 신입도 첫날부터 같은 절차를 실행합니다.
- **대표가 물어보지 않고도 상황을 알아야 할 때.** 누가 무엇을 언제 돌렸고 어디서 실패했는지가 한 화면에 모입니다.
- **같은 일을 매달 반복할 때.** 매번 다시 설명하는 것과, 클라이언트 이름만 바꿔 실행하는 것의 차이입니다.
- **마케팅 실무에 바로 쓸 도구가 필요할 때.** 인스타그램 저장 게시물, 유튜브 댓글 수집, SEO 크롤링처럼 이 업계에서 반복되는 작업이 이미 들어 있습니다.
- **빈 화면부터 시작하고 싶지 않을 때.** 킥오프에서 워크플로 30개와 대시보드를 만들어 드립니다.

### 둘을 같이 쓰셔도 됩니다

서로 배타적인 도구가 아닙니다. 개인이 하는 일회성 사무 업무는 Cowork로, **팀이 반복하는 마케팅 프로세스는 Twixy로** 나눠 쓰는 것도 좋은 조합입니다.

## 6. 도입에 필요한 것

### 준비물

| 항목 | 설명 |
|---|---|
| macOS 또는 Windows PC | 일반 업무용 컴퓨터면 충분합니다 |
| Google Chrome | 자동화가 Chrome으로 동작합니다 |
| 조사할 사이트의 계정 | Twixy 전용 브라우저 프로필에서 한 번만 로그인합니다 |
| 인터넷 | 특별한 방화벽 설정은 필요 없습니다 |

**필요 없는 것**: 서버 구축, IT 담당자, 데이터 이전, 기존 도구 교체.

### 도입 절차 — 팀을 바로 세팅해 드립니다

빈 화면부터 시작하지 않습니다. **저희가 팀에 맞는 워크플로 30개와 대시보드를 만들어 드리고, 팀은 첫날부터 실행만 하면 됩니다.**

| 단계 | 하는 일 |
|---|---|
| **1. 킥오프** | 팀의 업무를 듣고, 100개 워크플로 카탈로그에서 필요한 30개를 함께 고릅니다. 무엇을 골라야 할지 모르셔도 됩니다 — 그 자리에서 같이 정합니다 |
| **2. 셋업** | 고른 워크플로 30개와 맞춤 대시보드를 저희가 구축해 드립니다 |
| **3. 실행·모니터링** | 팀은 바로 실행합니다. 대시보드에서 모든 고객의 진행 상황이 보입니다 |

**받으시는 것**

- **워크플로 30개** — 팀 업무에 맞게 선정해 구축. 첫날부터 바로 실행 가능합니다.
- **맞춤 대시보드** — 팀에 필요한 KPI를 한눈에. 모든 고객의 진행 상황이 실시간으로 보이고, 업무가 막히면 어디서 막혔는지 바로 확인됩니다.
- **지속 관리** — 사이트 구조가 바뀌어 워크플로가 멈추면 저희가 고칩니다. AI 비용 효율화도 계속 맡습니다.

### 파일럿 기간 지원

- 이메일·채팅 **비동기 지원** — 영업일 기준 1일 이내 회신
- 주 1회 30분 점검 미팅
- **실행 로그 기반 문제 해결** — 워크플로가 실패하면 어느 단계에서 무슨 오류가 났는지 로그에 남습니다. 그 실행 기록만 보내주시면 화면 녹화 없이 원인을 찾습니다.

## 7. 보안과 프라이버시

**Q. Twixy는 어디서 실행되나요?**
**직원 각자의 컴퓨터에서 실행되는 데스크탑 앱**입니다. 워크플로 구성과 실행 모두 로컬에서 이뤄집니다. Twixy 서버가 원격으로 여러분의 계정을 조작하지 않습니다.

**Q. 결과 파일은 어디에 저장되나요?**
**본인 컴퓨터의 지정된 작업 폴더 안**에 파일로 저장됩니다. Twixy의 자동화는 그 폴더 밖에 파일을 쓰지 못하도록 제한되어 있고, 어떤 폴더를 허용할지는 설정에서 직접 확인하고 바꿀 수 있습니다.

**Q. 컴퓨터 밖으로 나가는 것은 무엇인가요?**
세 가지입니다.
1. **AI 처리 요청** — 각 단계가 처리해야 하는 텍스트가 AI 모델 제공사로 전송됩니다.
2. **웹 검색어** — 검색을 사용하는 단계에서 검색어가 전송됩니다.
3. **계정·팀 정보** — 로그인, 팀 구성, 공유 워크플로 정보, 사용량이 Twixy 클라우드에 저장됩니다.

클라이언트 파일이 통째로 업로드되지는 않습니다. **각 단계가 실제로 처리하는 내용만** 전송됩니다.

**Q. 저희 데이터로 AI를 학습시키나요?**
아닙니다. AI 처리는 상용 API를 통해 이뤄지며, 고객 데이터로 모델을 학습시키지 않습니다.

**Q. 브라우저 자동화가 저희 계정에 어떻게 접근하나요?**
**본인 컴퓨터의 Chrome, 그중에서도 Twixy 전용 프로필**에서 동작합니다. 한 번 로그인해두면 그 정보는 Chrome 자체 저장소에 남습니다. **Twixy가 비밀번호를 수집하거나 업로드하지 않습니다.** 평소 쓰는 Chrome은 영향을 받지 않고, 어떤 사이트를 다룰지는 워크플로를 만드는 쪽이 정합니다.

**Q. 승인하지 않은 일을 AI가 할 수도 있나요?**
워크플로는 설정된 것만 실행하며, **모든 실행이 기록됩니다.** 실행 로그에 어떤 동작을 했고 결과가 무엇이었고 어디서 오류가 났는지가 시각과 함께 남습니다. 워크플로 중간에 **사람이 확인하고 넘어가는 단계**를 넣을 수도 있습니다. AI 결과물에 대한 정식 승인·결재 기능은 **준비 중**입니다.

**Q. 팀에서 누가 무엇을 볼 수 있나요?**
팀은 워크스페이스를 공유하며, 공유한 워크플로는 추가한 팀원에게 보입니다. **세분화된 권한 관리는 준비 중**입니다. 현재는 서로 신뢰하는 소규모 팀을 전제로 설계되어 있습니다.

**Q. 클라이언트 기밀은 어떻게 되나요?**
워크플로가 다루는 데이터는 대개 **공개된 마케팅 정보**입니다(경쟁사 프로필, 공개 게시물, 자사 애널리틱스). 민감한 클라이언트 데이터를 다루는 업무는 파일럿 초기에는 제외하고 시작하시길 권합니다.

**Q. 워크플로가 중간에 실패하면요?**
**조용히 실패하지 않습니다.** 대시보드에 실패로 표시되고, 로그에 어느 단계에서 어떤 오류가 났는지 남습니다. 설정에 없는 재시도나 임의 진행은 하지 않습니다.

**Q. 데이터를 삭제할 수 있나요?**
로컬 파일은 일반 파일과 똑같이 삭제하시면 됩니다. 계정·팀 데이터 삭제는 지원팀에 요청해주세요.
