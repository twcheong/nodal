# Demo Scenario Script — Competitor Research Workflow

Covers the "Scenario" rows of the material table: the workflow **input**, the execution beats, the expected **output**, and the **reuse** step. Use this script both to run the live demo and to capture the four scenario screenshots.

Demo arc: **Build → Run → Reuse → Share → Monitor → Review** (~8 minutes)

---

## 1. Workflow input (start of demo)

Paste-ready input for the workflow builder:

```
Competitor research for a social media agency client.

Client: Maple & Co. Coffee (Toronto café brand)
Competitors: Balzac's Coffee Roasters, Pilot Coffee Roasters, Dineen Coffee Co.

For each competitor, using the browser:
1. Visit their Instagram profile and record follower count, posting
   frequency (last 30 days), and the 3 most recent post themes.
2. Visit their website and note current promotions or campaigns.
3. Note the content formats they use most (reels, carousels, statics).

Then produce a one-page summary:
- Table comparing the three competitors
- 3 observations on what is working for them
- 3 content opportunities for Maple & Co. Coffee

Save the result as a document in the client workspace folder.
```

> Swap in a real prospect's client and competitors before a live demo — recognition sells.

**Talk track:** "This is the exact research your social media manager does by hand every time you onboard a client — usually 2–3 hours of tabs, copying, and pasting."

## 2. Build (1 min)

- Create the workflow from the input above (or open the pre-built one as backup).
- Point out the nodes: *browser research → extract → summarize → save document*.
- **Say:** "You describe the process once. Twixy turns it into a workflow your whole team can run."

## 3. Run — browser execution (2–3 min)

- Run the workflow; show Chrome visiting the competitor pages and collecting data.
- **Say:** "This isn't a chatbot writing from memory — it's doing the actual browser work: visiting the pages, reading what's really there, today."
- Backup plan: keep a completed run in the run log in case of network/site issues.

## 4. Result (1 min)

- Open the produced summary document: comparison table + observations + opportunities.
- **Say:** "From client name to client-ready research. Your manager reviews and refines it instead of assembling it."

## 5. Reuse for another client (1 min) — the money moment

- Duplicate the workflow, change only the client/competitor names (e.g. a fitness studio), and start the run.
- **Say:** "This is the difference from ChatGPT. There, this is a prompt someone retypes from their personal notes. Here, it's an asset your agency owns — every new client starts at 90% done."

## 6. Share (30 sec)

- Share the workflow to a teammate in the team workspace.
- **Say:** "Your best people's process stops living in their heads. New hires run the same playbook on day one."

## 7. Monitor & review (1 min)

- Show the workflow status dashboard (running / completed / failed / pending).
- Open the execution log of the finished run: actions, results, errors, timestamps.
- **Say (to founder):** "You see what ran, what it did, and what came out — without asking anyone for a status update."

## Do not claim during the demo

Per the feature-accuracy rules: no "works on every website / never fails / no setup needed / replaces hiring." If a step fails live, use it: open the execution log and show exactly where and why it failed — that's the visibility story.
