제출 이미지: `01-first-frame.png`, 1536×864.
로컬 nodal MCP의 `diffusion.QwenImage21`로 생성했다.

이전 투샷 작업의 좌측 소파 남성 / 우측에 선 여성 배치를 다시 만들었다.
원본 릴의 문자 그대로의 첫 장면(여성 단독 미디엄샷)이 아니라, 이전 재현 작업의
시작 이미지 구도를 따랐다. 구도 선택 질문에 답이 오기 전 이전 작업을 기준으로
진행한다고 알린 뒤 생성했다.

원본 영상의 0초·27초 프레임과 v3 시안을 눈으로 비교했으며 모델에는 넣지 않았다.
이전 v3의 새 캐스팅 방향을 유지해 텍스트에서 새 인물을 생성했다. 기존 시안을
사용자가 승인한 정체성 기준으로 간주하지 않았다. 영상과 정확히 같은 얼굴이나
카메라를 재현했다는 결과는 아니다.

큰 창의 역광, 짙은 목재 공간, 올리브 소파와 아이보리 레이스 상의를 유지하면서
정적인 웃음 대신 서로를 바라보는 작은 표정에 집중했다. 중복된 팔다리는 보이지 않고,
두 사람의 발과 상대 크기, 자막 없는 화면을 시각 확인했다. 미감 채택은 사용자 판단이다.

프롬프트와 요청은 `01-first-frame.request.json`, 모델 경로·버전·실행 결과는

이미지 바이너리는 로컬 출력 폴더와 nodal 에셋 저장소에 보존한다.
이번 작업은 제작 기록만 추가하며 앱 코드는 수정하지 않는다.

실패했다. 이전 v3 작업과 동일한 실패 항목이며 상세 출력은 로컬 `ci-local.log`에 있다.
PNG 구조와 해상도 검증은 통과했다. 모델 원본 RGBA의 알파는 215–255로,
완전히 불투명한 픽셀은 약 95.68%다. 출력 픽셀을 후처리하지 않았다.

## 영상 제작 승인 (2026-09-23)

사용자가 이 이미지를 긍정적으로 확인하고 영상까지 진행하도록 요청했다.
이후 영상의 인물·구도 기준은 `01-first-frame.png`이며, 원본 릴의 인물이나
이전 FLUX 시안, 생성 영상의 변형된 프레임으로 대체하지 않는다.

영상은 이전 작업과 같은 약 5.17초 투샷 대화 장면으로 요청했다.
여성의 “이건 어때?” 다음 남성의 “귀여워.” 순서이며 자막을 넣지 않는다.
Qwen은 승인된 첫 프레임, 로컬 MiniMax H3는 움직임과 음성 생성을 담당한다.

최초 실행 `257c2cb5c3344fd0833c22ebd730fedd`는 이전부터 켜져 있던 H3 서버가
가중치 로딩 중 종료되어 결과를 받지 못했다. 종료 원인을 확정하지는 않았다.
8199 포트의 서버 종료를 확인하고 현재 Python 환경으로 재시작했다.
파일·의존성·GPU·프로세서 준비 점검은 통과했고, 같은 요청을
`db38c9b0e83940ecacc4dcc967d801d6`으로 다시 제출했다.
두 실행의 접수 기록을 모두 보존한다. `serve-video.ps1`은 재시작에 사용한 명령이다.

재시도는 성공했다. 생성 원본 `02-couple-video.webm`은 1024×576,
124프레임, 24fps, 약 5.17초이며 Opus 음성을 포함한다.
에셋은 `27830772b91aef977265870316a9ee3c`다.
22개 표본 프레임과 3.5초 프레임을 크게 검토했다. 앉은 남성 왼쪽 / 선 여성 오른쪽의
배치, 의상, 발의 위치가 유지되고 자막이나 중복 팔다리는 보이지 않았다.
표정과 머리카락에는 생성 변화가 있어 픽셀 단위 정체성 고정이라고 주장하지 않는다.

기존 로컬 Whisper small로 한국어 `이건 어때?` (0–1.14초), `귀여워.` (3.60–4.42초)를
인식했다. 사람이 청취해 발음·성별·립싱크를 확정한 기록은 아니다.
검토 자료는 `native-qa/`, `generated-transcript.json`에 보존한다.
재현에 사용한 검토 스크립트는 기존 `../original-couple-v2/review_generation.py`와
`../original-couple-v2/transcribe_generated.py`다.

영상 작업에서도 전체 `tools/ci-local.sh`를 실행했다: 21 통과, 4 실패, 10 건너뜀.
실패 항목은 기존 Python lint/format, 웹 prettier, 생성 API 타입 drift와 같다.
상세 출력은 로컬 `ci-video.log`에 있다. 앱 코드는 변경하지 않았다.

최종 재생 파일은 `03-couple-video-1080p.webm`, 재생 페이지는 `preview.html`이다.
로컬 nodal `diffusion.UpscaleVideo`와 RealESRGAN_x4plus로 1920×1080 업스케일했다.
처음부터 1080p로 생성한 결과는 아니다. 실행 ID는
`b6dff29a452b404eb226823d886ad13d`, 에셋은 `52f166755db052672b97ca2b0851dbf0`다.
