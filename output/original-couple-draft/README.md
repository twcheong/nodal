# 오리지널 커플 영상 시안 — 2026-09-20

참고 영상은 ‘옷을 보여주는 사람과 매번 귀엽다고 반응하는 연인’이라는 상황과
대화 리듬에만 사용한다. 참고 영상의 이미지, 인물 얼굴, 프레임은 생성 입력으로
사용하지 않는다. 자막 없는 영상으로 제작한다.

## 새 인물과 공간

- 여성: 어깨 길이의 검은 머리, 아이보리 골지 가디건, 청바지.
- 남성: 가르마를 탄 검은 머리, 얇은 둥근 안경, 베이지 가디건, 밝은 이너.
- 공간: 오렌지색 소파, 회색 벽, 왼쪽 뒤의 오크 책장, 오른쪽 창과 베이지 커튼.
- 빛: 오른쪽 창에서 들어오는 따뜻한 오후 자연광.
- 모든 후속 이미지의 정체성 기준은 새로 생성한 `01-cast-room.png`다.
  다른 컷의 변형을 누적해서 다음 컷의 기준으로 삼지 않는다.

## 제작 경로

1. nodal MCP → 로컬 SDXL: 새 인물 두 명과 거실을 텍스트만으로 생성.
2. nodal MCP → 로컬 FLUX.2 Klein Base 4B: 기준 이미지를 참조해
   투샷, 여성 미디엄, 남성 리액션 장면을 1536×864로 생성.
3. nodal MCP → 로컬 MiniMax H3 Pruned: 새 장면 이미지를 시작 프레임으로 영상화.
4. 영상 QA: 디코딩한 프레임, 실제 해상도·길이·프레임 수, 로컬 음성 인식 확인.

외부 이미지·영상 생성 서비스는 사용하지 않았다. FLUX 노드는 기존
`codex/flux2-base-test` 소스 체크아웃에서 실행한다. `serve_images.py`에 경로를
기록했고 해당 체크아웃은 수정하지 않았다. 영상 노드는 현재 체크아웃에서 실행한다.
FLUX 소스 커밋은 `5758ea2eefba20de97c02487dd6ec1b2eaa5f57b`다.

1536×864 영상 시험은 첫 추론 단계에 322.68초가 걸려 시안 용도로 중단했다.
완성 시안의 요청은 `05b-woman-video.json`이며, 1024×576/20스텝 생성 후
nodal의 로컬 RealESRGAN으로 1920×1080 복원한다. 네이티브 1080p 생성이 아니다.
영상 저장은 기존 VP9 CRF 30에서 CRF 18로 바꿔 후처리 전 압축 손실을 줄였다.

## 이후 전체 영상의 구성 시안

| 컷  | 화면                           | 대사/행동                                     |
| --- | ------------------------------ | --------------------------------------------- |
| 1   | 여성 미디엄, 아이보리 가디건   | 내일 우리 놀러 갈 때 입을 옷. 어때?           |
| 2   | 남성 리액션                    | 귀여워.                                       |
| 3   | 같은 여성·같은 위치, 다음 의상 | 그럼 이건?                                    |
| 4   | 같은 남성 리액션               | 귀여워.                                       |
| 5   | 여성 미디엄                    | 다 귀엽다고만 하지 말고.                      |
| 6   | 남성 리액션, 잠깐 생각         | 예뻐.                                         |
| 7   | 투샷                           | 여성이 웃음을 참다가 웃고 남성도 따라 웃는다. |

전체 구성표는 기획이며, 생성 완료 범위는 최종 결과 기록에 별도로 표시한다.
의상 변경은 의도한 연출이고 얼굴·머리·체형·거실 배치·광원은 유지한다.

각 요청 JSON에 모델 경로, 프롬프트, seed, 참조 파일을 보존한다. MCP receipt의
run ID와 완료 상태 및 에셋 해시를 함께 보관한다. 이미지·영상 바이너리는 로컬에
보존하고 Git에는 제작 기록과 재실행 스크립트만 추가한다.

## 완료된 시안과 검토

- 장면 이미지 3장: 투샷, 여성 미디엄, 남성 리액션. 각각 1536×864.
- 영상 한 컷: 1024×576 생성 원본과 1920×1080 복원본.
  두 파일 모두 24fps, 124프레임, 약 5.17초다.
- 복원 전후 디코딩한 오디오 WAV의 SHA-256이 동일하다.
- 0.25초 간격과 마지막 프레임을 포함한 22개 샘플에서 인물·의상·공간이
  시안 수준으로 유지되고, 자막·워터마크는 보이지 않았다.
- 한국어 ASR 인식 확률은 약 99.6%지만, 의도한 “입을 옷”을 “입으로”로 인식했다.
  따라서 **대사 정확성을 통과 처리하지 않았다.** 발음 또는 인식 오류인지 청취 확인이 필요하다.
  대형 Whisper 캐시는 참조 정보만 있고 가중치가 없어 교차 검증에는 사용하지 못했다.
- 전체 구성표의 나머지 컷과 최종 편집본은 이번 시안에 포함되지 않는다.

## 코드 검증 결과

- 변경한 Python 파일의 ruff lint/format 및 `git diff --check`: 통과.
- 실제 WebM 영상·스테레오 오디오·그래프 메타데이터 보존 테스트: 통과.
- `tools/ci-local.sh` 전체 실행: 21 통과, 4 실패, 10 건너뜀.
- 남은 실패: 기존 `output/zimage-training` 등의 Python lint/format,
  변경하지 않은 웹 파일의 prettier, 생성 API 타입 drift. 이번 영상 작업에서
  해당 파일들은 수정하지 않았다. 상세 로그는 `ci-local.log`에 보존한다.
