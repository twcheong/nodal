# 원본 릴스의 샷 구성 재현

사용자 지적: 이전 5초 결과는 두 대사를 모두 투샷으로 처리했지만 원본은 여성 단독 샷과 남성 역방향 리액션으로 나뉜다. 이번 작업은 승인된 Qwen 투샷의 인물과 공간을 기준으로 원본 전체의 11개 샷을 다시 구성한다.

## 고정 기준

- 원본: `../reel-DcvQpQfJ6EB/source-video.mp4`, Instagram `DcvQpQfJ6EB`.
- 인물·공간 기준: `../original-couple-qwen21/01-first-frame.png`. 생성된 변형 프레임을 새 정체성 기준으로 승격하지 않는다.
- 원본 30fps, 1,015프레임. 컷 경계: 0, 122, 153, 228, 289, 354, 412, 471, 510, 596, 729, 1015.
- 목표 편집 길이: 33.833333초. 컷 길이: 122, 31, 75, 61, 65, 58, 59, 39, 86, 133, 286프레임.
- 원본 프레임은 구도·렌즈·블로킹·의상 순서를 참조한다. 얼굴은 승인 이미지와 nodal에서 추출한 얼굴 참조를 따른다.
- 이미지 생성·보정·제작용 크롭은 nodal 로컬 Qwen-Image-2.1 및 image 노드만 사용한다. 영상은 nodal 로컬 MiniMax H3. 외부 생성 서비스는 사용하지 않는다.
- 원본 오디오를 복사하지 않고 한국어 대사를 생성한다. 자막·중앙 타이틀·배경음악은 생성하지 않는다.

## 재현 기록

각 `*.request.json`은 실제 그래프와 프롬프트, seed, 입력 경로를 보존한다. `*.receipt.json`은 서버와 실행 ID, `*.status.json`은 결과, `*.files.json`은 에셋 ID와 SHA256을 보존한다. 첫 이미지 요청만 기존 MCP 템플릿 형식이다.

Qwen 모델 리비전은 `790c92633540aa0cb11d9abf19eb46d861714758`, H3 Pruned 리비전은 `1a0ef5e65b639e84af81d883817968532180e9c7`이다. Qwen 40 steps/1536×864, H3 20 steps/1024×576를 사용한다. H3 출력은 24fps이고 최종 편집에서 원본과 같은 30fps 컷 경계에 맞춘다.

`nodal_job.py`는 그래프를 검증 후 제출하며 기존 receipt가 있으면 중복 제출을 거부한다. 상태 조회 시 성공한 결과를 내려받고 해시를 기록한다. GPU가 하나이므로 Qwen 이미지 큐를 끝낸 뒤 H3 영상 큐를 실행한다.

## 검수와 편집

`compare_frames.py`는 원본과 샷별 시작 이미지를 나란히 놓은 QA 이미지를 만든다. QA용 리사이즈이며 제작 이미지 입력으로 사용하지 않는다. `shot-NN-match.png`가 있으면 해당 보정본을 비교한다.

`assemble.py`는 검수한 샷별 영상 구간을 정확한 프레임 수로 편집한다. 음성과 영상에 같은 시간 변환을 적용하고, 음성은 atempo로 음높이를 유지한다. 대사가 잘리거나 0.85–1.35 범위를 벗어나는 시간 조정이 필요하면 컷을 다시 생성한다. 자동 무음 패딩은 필터 꼬리의 100ms 이내만 허용한다. 각 컷 경계에는 5ms 오디오 페이드를 적용한다.

편집기 smoke 검증은 실제 영상의 두 구간을 12+18프레임으로 연결하고 첫 구간을 1.225배 속도로 조정했다. 독립 디코드 결과 30fps/30프레임과 오디오 1.000초가 확인됐다. WebM의 밀리초 타임베이스로 계산한 마지막 프레임 끝 시각은 1.000333초다.

현재 제작 상태와 선택한 프레임은 `qa/frame-review.json`에 기록한다. 완료되지 않은 결과를 완료로 기록하지 않는다. 대형 이미지·영상은 로컬 산출물로 두고 재현용 요청·실행·검수 기록만 버전 관리한다.

`collect_video_qa.py`는 완료된 H3 실행만 수집하고 기존 로컬 프레임/오디오 추출 및 CPU Whisper 검수를 실행한다. 영상 생성 요청은 제출하지 않는다. 자동 ASR은 대사와 구간 검토를 돕는 자료이며, 시각 검수 또는 음성의 완전한 정확성을 대신하지 않는다.

## 저장소 검사

이번 작업 중 `tools/ci-local.sh` 전체를 실행한 결과 21개 통과, 4개 실패, 10개 건너뜀이었다. 실패 항목은 기존 작업 트리의 Python lint/format, web prettier, API 타입 drift다. 로그는 `ci-local.log`에 있다. 이번 산출물의 Python 스크립트는 별도로 ruff lint/format 검사를 통과했다. 관련 없는 기존 파일은 수정하지 않았다.
