참고 영상의 매력과 공간 밀도를 살리되 원본 이미지 자체를 재사용하지 않는다.

인물의 표정은 아직 비교적 정돈된 미소이며, 미감의 최종 채택은 사용자의 판단으로 남긴다.

## 제작 방향

- v2의 정상적인 성인 비율과 앉은 남성 왼쪽 / 선 여성 오른쪽 구도를 유지한다.
- 베이지 니트와 빈 거실을 짙은 목재 벽, 올리브 소파, 버건디 러그,
  빈티지 수납장·식물·도자기와 따뜻한 빛으로 재설계한다.
- 새 얼굴·헤어·의상·표정을 시도한다. 이전 캐릭터의 정체성 보존을 요구한 작업이 아니다.
- 원본 릴의 0초·27초 프레임은 시각 분석에만 사용했다. 모델 입력에 넣지 않았다.
- 모든 생성·편집은 nodal MCP와 로컬 FLUX.2 Klein Base 4B로 수행했다.
  1536×864, 32 steps. 외부 이미지 생성 서비스는 사용하지 않았다.
